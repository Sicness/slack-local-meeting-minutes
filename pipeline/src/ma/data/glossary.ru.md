# Словарь терминов

Используется в двух местах:
- **Whisper** (подсказка в каждом окне): как писать слова. Лимит ~220 токенов, поэтому туда идут только строки с пометкой `!` — термины, которые Whisper без подсказки путает. Без `!` — то, что Whisper и так пишет правильно. Порядок строк = приоритет, не поместившиеся пишутся в журнал
- **Модель протокола** (системный промпт, M4): весь словарь, чтобы протокол исправлял ошибки распознавания

Рабочая копия — `~/MeetingAssistant/glossary.txt` (вне репозитория: туда пойдут имена коллег). `ma` создаёт её из этого списка при первом запуске, дальше правится она. Формат: по одному термину в строке, `!` в начале — в подсказку Whisper, `ошибка => правильно` — замена после расшифровки, `#` — комментарий. После правки замен хватает `ma process <id> --from transcript`.
